# Amiasea Dev Container Image

The Amiasea development environment for building and operating Amiasea engineering artifacts.

## Image

```text
ghcr.io/amiasea/amiasea
```

## Contents

* Ubuntu-based Dev Container environment
* PowerShell
* Microsoft.PowerShell.SecretManagement
* Microsoft.PowerShell.SecretStore

## Usage

This image is intended to be used as the base development environment for Amiasea engineering repositories through GitHub Codespaces and Dev Containers.
